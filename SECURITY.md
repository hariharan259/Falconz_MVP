# Security Policy

## Supported Versions

We currently support the following versions of FalconZ for security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

*(Note: We are currently in Pre-release/MVP stage)*

## Reporting a Vulnerability

If you discover a security vulnerability in the FalconZ platform (especially concerning unauthorized drone access or C&C override exploits), please do **NOT** report it in the public issue tracker.

Instead, please send an email to `security@falconz.example.com`. We will strive to acknowledge your report within 48 hours and provide a timeline for the fix.
