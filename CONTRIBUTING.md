# Contributing to FalconZ

First off, thank you for considering contributing to FalconZ! It's people like you that make FalconZ such a great platform.

## Getting Started

1. **Fork & Clone**: Fork the repository and clone it to your local machine.
2. **Setup**: Run `make install-deps` in the root directory to install dependencies for all polyglot microservices.
3. **Branching Strategy**: We use the `feature/` and `bugfix/` prefix for branches. E.g., `feature/ai-swarm-logic`.

## Code Style
- **Python**: Follow PEP8. We use `black` and `flake8`.
- **Node.js/Frontend**: We use `eslint` and `prettier`. 
- Please ensure your IDE utilizes the `.editorconfig` provided in the root directory.

## Pull Request Process
1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface, if applicable.
3. Use the provided PR template. PRs require at least one approving review from a core maintainer before merging.

## Issues
Please use our Issue Templates when reporting bugs or requesting features. Include as much telemetry or log data as safely possible.
